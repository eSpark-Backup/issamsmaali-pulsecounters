# issamsmaali-pulsecounters

**Design: Four Pulse Counters Circuit Design**  

Design a device capable of handling impulse readings without the use of a concentrator. The project involves designing a system that integrates a COUNTER IC and an I2C MUX to support four or more pulse inputs. The system will also include power conversion from a 24V DC input to appropriate voltage levels to power the circuitry.The project aims to design a system that can manage multiple pulse inputs (four or more) by incorporating a COUNTER IC and an I2C MUX (such as the MAX7357, as an example).

**1. Circuit Design & Development:**
  - Design a power conversion circuit to step down the 24V DC input to appropriate voltage levels for the 5V DC and COUNTER IC and I2C MUX.  
  - Ensure the system can handle input voltages ranging from 2V to 24V DC.  
  - Design a circuit that can handle impulse readings from Reed Switch and/or PNP transistor inputs.  
  - Integrate a COUNTER IC and an I2C MUX to support up to four pulse inputs.  
  - Integrate status LEDs for each pulse input to provide visual feedback on pulse activity.  
  - Ensure the LEDs are clearly visible and appropriately labeled.  
  - Test Points
    
**2. Input Specifications:**
  - Inputs: Reed Switch and/or PNP transistor.  
  - Voltage Range: 5V to 24V DC  
  - Frequency: Up to 35 Hz.
    
**3. Component Selection:**
  - Research and select appropriate electronic components for the design.  
  - Ensure the design meets cost, reliability, and space constraints.
    
**4. Documentation:**
  - Prepare detailed schematics, PCB layouts, and technical documentation for production.
